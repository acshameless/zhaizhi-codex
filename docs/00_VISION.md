# 摘纸 · 产品愿景

版本 v1.0 · 2026-09-20 · 状态：草案

---

## 一句话

> 摘纸是一个安静的个人引文图书馆：把读过的书里值得再看一眼的句子摘下来、存住、随时找得回来。

副标题（README / 站点 meta 用）：

> A quiet library for the sentences that changed you.

## 要解决的问题

读过的书里，真正留下来的往往只是几句话。但今天这几句话散落在各处，且各有各的失效方式：

- 微信读书的划线锁在平台里，导不出、搜不全、随时可能消失。
- 备忘录能存，但不能按书回看，也不能跨书检索。
- Notion / Obsidian 能存，但它们是笔记工具，不是图书馆：录入路径长，回顾路径更长。
- 纸质书上的划线，基本等于丢失。

结果是你记得"我读过某句话"，但找不到它。

摘纸只解决这一件事：让句子进来得足够快，找回来得足够快，并且十年后仍然在。

## 三条产品承诺

所有技术决策都为这三条服务，冲突时按此优先级裁决。

| 承诺 | 含义 | 验收口径 |
| --- | --- | --- |
| 录入成本 ≤ 30 秒 | 看到一句好句子，30 秒内进入系统 | 电脑：IDE 里加一段并 push；手机：浏览器在 GitHub 上追加并提交 |
| 找回成本 ≤ 两步 | 任意一句都能被找回 | 打开站点 → 输入任意片段/作者/书名/标签 → 命中句子本身，点击回到原书位置 |
| 十年可用 | 不绑任何专有服务 | 纯文本 + Git 为唯一数据源，无数据库、无账号、无运行时后端；站点可由任何静态托管重建 |

## 设计哲学

视觉基调直接采用 [Kami](https://github.com/tw93/kami)（TW93，MIT）的设计语言，不凭空模仿：

- 暖纸底色 `#f5f4ed`，永远不用纯白。
- 唯一强调色：墨蓝 `#1B365D`。其余全部是暖灰，不引入第二种颜色。
- 衬线字体承担标题与正文，用字号和留白建立层级，而不是靠颜色和线条。
- 动画克制到几乎不存在，只保留必要的淡入与状态过渡。
- 英文衬线 Charter，中文衬线自托管 Noto Serif SC（OFL）；Kami 使用的仓耳今楷02 个人使用免费、商用需授权，未获授权时不打包进站点。

产品气质关键词：Quiet · Paper · Editorial · Timeless。

## 我们不是谁

明确的非目标，写下来是为了长期抵抗范围蔓延：

- 不是笔记工具，不做编辑器、不做富文本、不做双链。
- 不是社交产品，不做关注、评论、点赞、Feed。
- 不是阅读管理工具，不做书单推荐、阅读进度追踪、书评社区。
- 不做多用户与账号体系：唯一的作者是你，其他人只是访客。
- 不在 MVP 引入 AI 生成内容：AI 只在未来的"导入/整理"环节作为工具出现，不介入展示与数据源。

## 长期形态

一个公开可访问的静态站点，背后是一个 Markdown 内容仓库。你往 `books/` 里放一本书，站点自动更新；你不再维护它，它也不会腐烂。
